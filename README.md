# 🏧 ATM Machine Simulation in Python

This project is a console-based simulation of an ATM machine developed in Python. It allows users to perform basic banking operations such as checking balance, depositing money, and withdrawing funds. It was developed as part of my internship project at Octanet.

## 🎯 Objectives

- Simulate the core functionalities of an ATM
- Handle user authentication (PIN-based)
- Perform operations like balance inquiry, deposit, and withdrawal
- Demonstrate the use of control flow, functions, and file/data handling

## 🧰 Technologies Used

- **Python 3**
- Console-based interface
- *(Optional)* File handling for data persistence

## 🔧 Features

- User login using PIN authentication
- View account balance
- Deposit money
- Withdraw money with validation
- Exit/Logout functionality

## 🖥️ How It Works

1. User is prompted to enter a valid PIN
2. After authentication, a menu appears with banking options
3. User selects the desired operation
4. The system processes and returns results accordingly
